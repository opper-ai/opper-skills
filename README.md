# Opper plugin for Claude

Agent Skills for building on [Opper](https://opper.ai), the EU-hosted AI gateway, plus the Opper MCP server (`https://api.opper.ai/mcp`).

- Skills: `opper`, `opper-api`, `opper-cli`, `opper-mcp`, `opper-multimodal`. Start with `opper`.
- MCP server: search the model catalogue without an account; everything that touches your account asks you to sign in through the browser first.

This branch is generated from [opper-ai/opper-skills](https://github.com/opper-ai/opper-skills) by `scripts/build-claude-plugin.sh` on every push to `main`. Change the skills there, not here.

Docs: https://docs.opper.ai · MCP setup: https://opper.ai/mcp · Support: https://opper.ai/contact
